# Handoff: כרטיס סיכום בלוק (Block Recap Share Card) — CrossFit Bat Yam

## Overview
כרטיס שיתוף אישי שמתאמן מייצר בלחיצת כפתור בסיום בלוק אימונים של 8 שבועות, בשני פורמטים: סטורי (1080×1920) ופיד (1080×1350). הכרטיס נבנה כ-HTML בתוך האפליקציה הקיימת ומצולם ל-PNG באמצעות html2canvas, כמו כרטיסי השיתוף הקיימים (`shareType: 'week'`, `'prboard'`).

## About the Design Files
הקבצים כאן הם **רפרנס עיצובי ב-HTML** — לא קוד production להעתקה כמו-שהוא. המשימה: לשחזר את העיצוב בסביבת האפליקציה הקיימת (vanilla HTML/JS, דפוס `shareCardEl()` עם מחלקות CSS כמו `.share-card`), כפונקציה שמקבלת אובייקט נתונים ומחזירה DOM לצילום. כל הסגנונות בקבצים הם inline — קל להמיר למחלקות לפי הקונבנציה של app.html.

## Fidelity
**High-fidelity.** פיקסל-פרפקט ברוחב 1080. צבעים, גדלים, ריווחים וטיפוגרפיה — סופיים. לרנדר ברוחב אמיתי (1080px) ולצלם ב-scale המתאים.

## Data Schema
כל מספר ומחרוזת הם משבצת (slot). אין תלות באורך מדויק — שמות ומספרים משתנים בין מתאמנים.

```js
{
  athlete: "דנה לוי",
  program: "CAPACITY PROGRAM · 8 WEEKS",
  dateRange: "12/07/2026 – 05/09/2026",
  hero: { pct: "+60%", label: "C2B/Pull Ups — חזרות לדקה", before: "5", after: "8", unit: "לדקה" },
  badges: [
    { icon: "🔥", name: "רצף ברזל", value: "9 ימים רצופים" },
    { icon: "⚡", name: "RX ללא פשרות", value: "14 מטקונים בתקן" },
    { icon: "💎", name: "שבוע מושלם", value: "4 שבועות של 5/5" }
  ],
  tests: [ // בדיוק 3
    { name: "Back Squat — שלשה כבדה", before: "85 ק\"ג", after: "100 ק\"ג",
      beforePct: 85, afterPct: 100, delta: "+18%", deltaAbs: "+15 ק\"ג", betterWhen: "higher" },
    { name: "מבחן אירובי — 3 סבבים", before: "18:42", after: "16:05",
      beforePct: 100, afterPct: 86, delta: "מהיר ב־14%", deltaAbs: "2:37", betterWhen: "lower" },
    { name: "C2B/Pull Ups — חזרות לדקה", before: "5", after: "8",
      beforePct: 63, afterPct: 100, delta: "+60%", deltaAbs: "+3 בדקה", betterWhen: "higher" }
  ],
  testsSummary: "✓ כל 3 המבחנים השתפרו", // מחושב
  attendance: { weeks: [4,5,3,5,4,2,5,3], done: 31, of: 40 },
  keep:    [{ title, detail } × 3],   // ✅
  improve: [{ title, detail } × 3],   // 🎯 מנוסח תמיד כיעד, לא ככישלון
  prs: [{ name: "Back Squat", value: "100 ק\"ג" } × עד 3], // סטורי בלבד
  trackedPct: "78% מהבלוק תועד"
}
```
רוחב הפסים: `pct = round(value / max(before, after) * 100)` לכל שורה בנפרד. בזמן — הזמן הארוך הוא 100%.

## Edge-Case Rules (ליישום בקוד)
1. **אין מדידה חוזרת למבחן**: פס "אחרי" מקווקו ריק (border dashed, ללא מילוי), ערך "לא נמדד", בלי צ'יפ דלתא (במקומו תג עמום "נמדד בשבוע 1 בלבד"). באדג' הגרף מתחלף ל"נמדדו שוב · X מתוך Y".
2. **פחות מ-5 אימונים מתועדים בבלוק**: ה-Hero מתחלף — במקום אחוז שיפור מציגים את מספר האימונים שתועדו (eyebrow: TRAINING LOG). בלי badges אם לא הושגו.
3. **אין שיאים אישיים**: שורה שקטה אחת במסגרת מקווקוות — "לא נרשמו שיאים חדשים בבלוק הזה" — בלי 🏆 ובלי זהב.
העיקרון: להראות פחות, לא להמציא. ההשוואה היחידה היא של המתאמן מול עצמו בשבוע 1.

## אילוצי html2canvas — חובה
- בלי `backdrop-filter`, בלי `filter: blur()`, בלי מסכות CSS, בלי `mix-blend-mode`
- מותר: גרדיאנטים לינאריים, border-radius, box-shadow, text-shadow, divים
- הגרף בנוי divים בלבד (לא canvas, לא ספריית תרשימים)
- הלוגו הוא הנכס הגרפי היחיד (מוטמע כ-base64 באפליקציה הקיימת)

## RTL
`dir="rtl"` על השורש. מספרים עם סימן (+18%), זמנים בטווח, ותאריכים עטופים ב-`<span dir="ltr">` או בצ'יפ flex — לשמר את הדפוס מהקבצים בדיוק. חץ ההתקדמות בצ'יפים הוא "←" (מצביע אל ה"אחרי").

## Design Tokens
- רקע כרטיס: `linear-gradient(150deg, #0F1830, #1A2848 55%, #23409A)`
- רצועה עליונה: `linear-gradient(90deg, #EF5B25, #F0C064)`, גובה 6px
- כתום מבטא: `#EF5B25` · זהב הישגים: `#F0C064` · כחול: `#23409A`
- טקסט: `#FFFFFF` · משני: `#B9C4E6` · עמום: `#8FA4D8`
- שורות/כרטיסים פנימיים: `rgba(255,255,255,.08)`, radius 18–22px · פסי גרף ריקים: `rgba(255,255,255,.10)` · פס "לפני": `rgba(143,164,216,.65)` · פס "אחרי": `#EF5B25`
- תגי badges: רקע `rgba(240,192,100,.10)`, מסגרת `1.5px solid rgba(240,192,100,.35)`
- מפרידי סקשנים: `border-top: 1px solid rgba(255,255,255,.15)`
- טיפוגרפיה: **Oswald** 500–700 לכותרות/מספרים באנגלית (letter-spacing .04–.18em) · **Heebo** 400–800 לעברית. גודל מינימלי בכרטיס: 18px.
